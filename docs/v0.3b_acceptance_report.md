## 4. Validation results

**Statistical validation** (details in `docs/event_study_statistical_validation.md`):
- The implemented test is close to nominal: size 0.046 / 0.051 / 0.049 at L = 1 / 3 / 6.
- With doubled event-window volatility, size rises to 0.32 for both the classical test and the
  placebo. That is why the event-induced-volatility diagnostic downgrades inference.

Notes on these figures:

## 5. Historical-integrity findings

**Point-in-time correctness** (replay tests):
- Events not yet known at the cutoff are ineligible.
- Windows whose bars are not final at the cutoff are withheld.
- Point-in-time studies whose bars were first retrieved after the cutoff are `UNVERIFIED` and
  stay point-in-time.
- A price correction observed after the cutoff is invisible to earlier cutoffs. Results after
  the correction form a new run; the old run is unchanged.
- A future split (NVDA 2024-06-10) is absent from point-in-time adjustment factors. Returns are
  unchanged, because a backward factor after the window scales every price equally.
- A confounder published in the window but available only after the cutoff is hidden
  point-in-time and shown in research mode.

**Defects found during development** (all fixed, each with a regression test):
- An exact fit produced a t-statistic.
- A run requested with robustness checks returned an earlier stored run without them.
- A yield study failed as a whole when a window ran past the data.
- The yield report's heading and Markdown table header were wrong.
- The confounder availability margin was too narrow.
- The documented offline event ingestion omitted `--start 2025-07-01`.

## 8. Limitations

- **No empirical equity event study.** Live Alpaca is unverified, so equity results are
  methodological validation only.
- **Inference scope:**
  - single-event inference is classical (normal, i.i.d. errors) plus a placebo check;
  - no BMP standardized, Kolari–Pynnönen, rank or sign tests;
  - no clustered or panel inference across assets.
- **Data and coverage:**
  - daily data only, so no intraday reactions;
  - confounder coverage is inferred from stored events, and no news, analyst or consensus
    source exists.
- **Persistence:**
  - point-in-time studies over backfilled bars are `UNVERIFIED`;
  - stored report Markdown is immutable, so rendering changes apply to new runs only.
- No optional LLM narrative (template reports only), and **no causal identification**.
